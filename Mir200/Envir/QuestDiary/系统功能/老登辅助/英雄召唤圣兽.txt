;英雄自动召唤圣兽（标志位 + 定时器补满版）
;引擎缺陷：
;  1、英雄释放召唤圣兽技能不会触发 [@HeroMagSelfFunc76]
;  2、引擎没有检测英雄技能等级的命令（H.CHECKSKILL 不存在）
;因此改用「标志位 + 个人定时器」方案：
;  - 英雄学习召唤圣兽技能时，QFunction-0.txt 的 [@HeroLearnMagic] 触发，
;    判断 <$H.LearnMagicID> = 76，给本体置标志位 [800] = 1。
;  - 玩家登录时，QManage [@Login] 检测 CHECK [800] 1，是则启动定时器 SetOnTimer 7 3。
;  - 定时回调 [@OnTimer7] -> 本脚本 [@英雄召唤圣兽_定时检测]，
;    周期检测英雄圣兽数量，不足上限则按英雄等级补召唤，直到补满。
;
;魔法ID：76 = 英雄召唤圣兽（Magic 表 MagID=76, MagName=英雄召唤圣兽, Job=2 道士, Descr=英雄）
;圣兽怪物名：圣兽（Monster 表）
;标志位：[800] = 1 表示本体英雄已学召唤圣兽
;规则：
;  1、本体未打标志位（英雄未学召唤圣兽）-> 不召唤
;  2、英雄不在线 -> 不召唤
;  3、数量上限按英雄等级分档（见下方「圣兽数量上限」等级范围）
;  4、英雄等级决定圣兽等级：40级=1级，每5级+1，封顶7级

[@英雄召唤圣兽_定时检测]
{
;========== 第一步：本体标志位判断（英雄是否已学召唤圣兽）==========
#IF
CHECK [800] 1
#ELSEACT
BREAK

;========== 第二步：英雄在线判断 ==========
#IF
CheckHeroOnline
#ELSEACT
BREAK

;========== 第三步：按英雄等级计算圣兽数量上限 ==========
;等级范围（测试用，可自行调整）：
;  40~49级 -> 1个
;  50~59级 -> 2个
;  60级以上 -> 3个
#IF
CheckHerolevel > 59
#ACT
MOV N$圣兽数量上限 3
GOTO @英雄召唤圣兽_数量检测
#IF
CheckHerolevel > 49
#ACT
MOV N$圣兽数量上限 2
GOTO @英雄召唤圣兽_数量检测

#IF
CheckHerolevel > 39
#ACT
MOV N$圣兽数量上限 1

;英雄不足40级，不召唤
BREAK

;========== 第四步：圣兽数量检测（同名圣兽是否已满）==========
[@英雄召唤圣兽_数量检测]
#IF
H.CHECKSLAVECOUNT < <$STR(N$圣兽数量上限)> 圣兽 0
#ELSEACT
BREAK

;========== 第五步：按英雄等级计算圣兽等级 ==========
#IF
CheckHerolevel > 69
#ACT
MOV N$圣兽等级 7
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 64
#ACT
MOV N$圣兽等级 6
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 59
#ACT
MOV N$圣兽等级 5
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 54
#ACT
MOV N$圣兽等级 4
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 49
#ACT
MOV N$圣兽等级 3
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 44
#ACT
MOV N$圣兽等级 2
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 39
#ACT
MOV N$圣兽等级 1
GOTO @英雄召唤圣兽_召唤

;英雄不足40级，不召唤
BREAK

;========== 第六步：召唤圣兽 ==========
[@英雄召唤圣兽_召唤]
#ACT
H.RECALLMOB 圣兽 <$STR(N$圣兽等级)> 9999 0 0 3 1
SENDMSG 6 你的英雄召唤了<$STR(N$圣兽等级)>级圣兽！
BREAK

}
