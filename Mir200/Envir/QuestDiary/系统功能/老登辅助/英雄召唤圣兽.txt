;英雄自动召唤圣兽（定时器补满版）
;引擎缺陷：英雄释放召唤圣兽技能不会触发 [@HeroMagSelfFunc76]
;因此改用个人定时器轮询：玩家登录时由 QManage [@Login] 启动定时器，
;定时回调 [@OnTimer7] -> 本脚本 [@英雄召唤圣兽_定时检测]，
;周期检测英雄的圣兽宝宝数量，不足则按规则补召唤，直到补满。
;
;魔法ID：76 = 英雄召唤圣兽（Magic 表 MagID=76, MagName=英雄召唤圣兽, Job=2 道士）
;圣兽怪物名：圣兽（Monster 表）
;规则：
;  1、英雄未学习召唤圣兽 -> 不召唤
;  2、技能等级决定圣兽数量上限：1级1个 / 2级2个 / 3级3个
;  3、英雄等级决定圣兽等级：40级=1级，每5级+1，封顶7级
;  4、英雄宝宝数量已达上限 -> 不补召

[@英雄召唤圣兽_定时检测]
{
;========== 第一步：英雄在线判断 ==========
#IF
CheckHeroOnline
#ELSEACT
BREAK

;========== 第二步：英雄是否学习召唤圣兽（等级>=1）==========
#IF
H.CHECKSKILL 英雄召唤圣兽 = 1
#ELSEACT
BREAK

;========== 第三步：按技能等级确定数量上限 ==========
#IF
H.CHECKSKILL 英雄召唤圣兽 = 3
#ACT
MOV N$圣兽数量上限 3
GOTO @英雄召唤圣兽_数量检测
#IF
H.CHECKSKILL 英雄召唤圣兽 = 2
#ACT
MOV N$圣兽数量上限 2
GOTO @英雄召唤圣兽_数量检测

#IF
H.CHECKSKILL 英雄召唤圣兽 = 1
#ACT
MOV N$圣兽数量上限 1

;========== 第四步：数量检测（同名圣兽是否已满）==========
[@英雄召唤圣兽_数量检测]
#IF
H.CHECKSLAVECOUNT < <$STR(N$圣兽数量上限)> 圣兽 0
#ELSEACT
BREAK

;========== 第五步：按英雄等级计算圣兽等级 ==========
#IF
CheckHerolevel > 69
#ACT
MOV N$圣兽等级 7
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 64
#ACT
MOV N$圣兽等级 6
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 59
#ACT
MOV N$圣兽等级 5
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 54
#ACT
MOV N$圣兽等级 4
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 49
#ACT
MOV N$圣兽等级 3
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 44
#ACT
MOV N$圣兽等级 2
GOTO @英雄召唤圣兽_召唤
#IF
CheckHerolevel > 39
#ACT
MOV N$圣兽等级 1
GOTO @英雄召唤圣兽_召唤

;英雄不足40级，不召唤
BREAK

;========== 第六步：召唤圣兽 ==========
[@英雄召唤圣兽_召唤]
#ACT
H.RECALLMOB 圣兽 <$STR(N$圣兽等级)> 9999 0 0 3 1
SENDMSG 6 你的英雄召唤了<$STR(N$圣兽等级)>级圣兽！
BREAK

}
