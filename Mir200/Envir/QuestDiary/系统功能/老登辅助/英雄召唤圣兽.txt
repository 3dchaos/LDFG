;英雄自动召唤圣兽（标志位逐个占位版）
;
;引擎缺陷：
;  1、英雄释放召唤圣兽技能不会触发 [@HeroMagSelfFunc76]
;  2、引擎没有 H.CHECKSKILL（检测英雄技能等级）命令
;  3、引擎没有任何「读取/清理英雄宝宝数量」的命令
;  4、个人数字变量 P0 在 OnTimer 回调里实测不保留，P 变量自维护失效
;因此改用「标志位 + 个人定时器 + 多槽位占位」方案：
;  - [801][802][803] = 三个独立槽位，每个 = 0 表示空、= 1 表示已占
;  - 最多同时 3 只圣兽（占满三个槽位）
;  - 死亡时无法精确清位，必须同时清掉所有槽位（少 1 只可接受，多召无风险）
;
;槽位映射：
;  [801] = 圣兽槽位 1（40~49级上限 = 1 只，仅用 [801]）
;  [802] = 圣兽槽位 2（50~59级上限 = 2 只，使用 [801][802]）
;  [803] = 圣兽槽位 3（60级以上上限 = 3 只，使用 [801][802][803]）
;其他标志位含义：
;  [800] = 1 表示本体英雄已学召唤圣兽（由 [@HeroLearnMagic] 设置）
;
;流程：
;  - [@HeroLogin]、[@Login]、[@HeroSlaveDie]：清掉 [801][802][803]，重新按需补满
;  - [@OnTimer7]：从 [801] 开始找第一个空槽位 [n]=0，置位并 H.RECALLMOB
;  - 上限判断：按英雄等级开放对应槽位（40级只开放 [801]，50级开放 [801][802] 等）

[@英雄召唤圣兽_定时检测]
{

;========== 第一步：本体标志位判断（英雄是否已学召唤圣兽）==========
#IF
CHECK [800] 1
#ELSEACT
BREAK

;========== 第二步：英雄在线判断 ==========
#IF
CheckHeroOnline
#ELSEACT
BREAK

;========== 第三步：按英雄等级寻找空槽位并占位 ==========
;60级以上 3 个槽位都可找
#IF
CheckHerolevel > 59
CHECK [801] 0
#ACT
SET [801] 1
GOTO @英雄召唤圣兽_真正召唤

#IF
CheckHerolevel > 59
CHECK [802] 0
#ACT
SET [802] 1
GOTO @英雄召唤圣兽_真正召唤

#IF
CheckHerolevel > 59
CHECK [803] 0
#ACT
SET [803] 1
GOTO @英雄召唤圣兽_真正召唤

;50~59级 2 个槽位
#IF
CheckHerolevel > 49
CHECK [801] 0
#ACT
SET [801] 1
GOTO @英雄召唤圣兽_真正召唤

#IF
CheckHerolevel > 49
CHECK [802] 0
#ACT
SET [802] 1
GOTO @英雄召唤圣兽_真正召唤

;40~49级 1 个槽位
#IF
CheckHerolevel > 39
CHECK [801] 0
#ACT
SET [801] 1
GOTO @英雄召唤圣兽_真正召唤

;英雄不足40级 或 所有槽位已满，不召唤
BREAK

;========== 第四步：按英雄等级计算圣兽等级（嵌套判断，最后一档兜底）==========
[@英雄召唤圣兽_真正召唤]
#IF
CheckHerolevel > 69
#ACT
MOV N$圣兽等级 7
GOTO @英雄召唤圣兽_执行召唤

#IF
CheckHerolevel > 64
#ACT
MOV N$圣兽等级 6
GOTO @英雄召唤圣兽_执行召唤

#IF
CheckHerolevel > 59
#ACT
MOV N$圣兽等级 5
GOTO @英雄召唤圣兽_执行召唤

#IF
CheckHerolevel > 54
#ACT
MOV N$圣兽等级 4
GOTO @英雄召唤圣兽_执行召唤

#IF
CheckHerolevel > 49
#ACT
MOV N$圣兽等级 3
GOTO @英雄召唤圣兽_执行召唤

#IF
CheckHerolevel > 44
#ACT
MOV N$圣兽等级 2
GOTO @英雄召唤圣兽_执行召唤

#IF
CheckHerolevel > 39
#ACT
MOV N$圣兽等级 1
GOTO @英雄召唤圣兽_执行召唤

;英雄不足40级，吐血回退（理论上第三步已经挡住）
BREAK

;========== 第五步：真正召唤圣兽 ==========
[@英雄召唤圣兽_执行召唤]
#ACT
H.RECALLMOB 圣兽 <$STR(N$圣兽等级)> 9999 0 0 3 1
SENDMSG 6 你的英雄召唤了<$STR(N$圣兽等级)>级圣兽！
BREAK

}
