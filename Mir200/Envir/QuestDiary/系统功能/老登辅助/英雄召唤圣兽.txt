;英雄自动召唤圣兽（标志位槽位 + 算术算等级版）
;
;引擎缺陷：
;  1、英雄释放召唤圣兽技能不会触发 [@HeroMagSelfFunc76]
;  2、引擎没有 H.CHECKSKILL（检测英雄技能等级）命令
;  3、引擎没有任何「读取/清理英雄宝宝数量」的命令
;  4、个人数字变量 P0 在 OnTimer 回调里实测不保留，P 变量自维护失效
;  5、平铺的多个 #IF/#ACT 不是互斥分支，条件为真会继续往下执行，导致一次触发招满 7~1 级
;因此改用「标志位槽位 + 个人定时器 + 算术算等级」方案：
;  - [801][802][803] = 三个独立槽位，每个 = 0 表示空、= 1 表示已占
;  - 最多同时 3 只圣兽（占满三个槽位）
;  - 死亡时无法精确清位，必须同时清掉所有槽位（少 1 只可接受，多召无风险）
;  - 圣兽等级用算术 (英雄等级-40)/5+1 直接算出，再夹到 1~7，杜绝平铺 #IF 连招
;
;槽位映射：
;  [801] = 圣兽槽位 1（40~49级上限 = 1 只，仅用 [801]）
;  [802] = 圣兽槽位 2（50~59级上限 = 2 只，使用 [801][802]）
;  [803] = 圣兽槽位 3（60级以上上限 = 3 只，使用 [801][802][803]）
;其他标志位含义：
;  [800] = 1 表示本体英雄已学召唤圣兽（由 [@HeroLearnMagic] 设置）
;
;流程：
;  - [@HeroLearnMagic]：学到召唤圣兽(魔法ID 76)时置 [800] 1，并清空三个槽位
;  - [@Login]、[@OnHeroSlaveDie]：清空 [801][802][803]
;  - [@OnTimer7]：每轮只补 1 个空槽位，命中即 GOTO 召唤并 BREAK，不连续往下落
;  - 圣兽等级：(<$H.LEVEL>-40)/5+1，夹在 1~7

[@英雄召唤圣兽_定时检测]
{

;========== 第一步：本体标志位判断（英雄是否已学召唤圣兽）==========
#IF
CHECK [800] 1
#ELSEACT
BREAK

;========== 第二步：英雄在线判断 ==========
#IF
CheckHeroOnline
#ELSEACT
BREAK

;========== 第三步：按英雄等级找第一个空槽位并占位（命中即跳走，互斥）==========
;60级以上：3 个槽位都可用，按 [801]→[802]→[803] 顺序找第一个空的
#IF
CheckHerolevel > 59
CHECK [801] 0
#ACT
SET [801] 1
GOTO @英雄召唤圣兽_算等级
BREAK

#IF
CheckHerolevel > 59
CHECK [802] 0
#ACT
SET [802] 1
GOTO @英雄召唤圣兽_算等级
BREAK

#IF
CheckHerolevel > 59
CHECK [803] 0
#ACT
SET [803] 1
GOTO @英雄召唤圣兽_算等级
BREAK

;50~59级：2 个槽位
#IF
CheckHerolevel > 49
CHECK [801] 0
#ACT
SET [801] 1
GOTO @英雄召唤圣兽_算等级
BREAK

#IF
CheckHerolevel > 49
CHECK [802] 0
#ACT
SET [802] 1
GOTO @英雄召唤圣兽_算等级
BREAK

;40~49级：1 个槽位
#IF
CheckHerolevel > 39
CHECK [801] 0
#ACT
SET [801] 1
GOTO @英雄召唤圣兽_算等级
BREAK

;英雄不足40级 或 所有槽位已满，本轮不召唤
BREAK

;========== 第四步：算术计算圣兽等级 ==========
[@英雄召唤圣兽_算等级]
#ACT
;圣兽等级 = (英雄等级 - 40) / 5 + 1
MOV N$圣兽等级 <$H.LEVEL>
DEC N$圣兽等级 40
DIV N$圣兽等级 5
INC N$圣兽等级 1

;夹到下限 1（40级：40-40=0 /5=0 +1=1，正常；但防御异常情况）
#IF
SMALL N$圣兽等级 1
#ACT
MOV N$圣兽等级 1

;夹到上限 7
#IF
LARGE N$圣兽等级 7
#ACT
MOV N$圣兽等级 7

GOTO @英雄召唤圣兽_执行召唤
BREAK

;========== 第五步：真正召唤圣兽 ==========
[@英雄召唤圣兽_执行召唤]
#ACT
H.RECALLMOB 圣兽 <$STR(N$圣兽等级)> 9999 0 0 3 1
SENDMSG 6 你的英雄召唤了<$STR(N$圣兽等级)>级圣兽！
BREAK

}
