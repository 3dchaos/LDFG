## 总体结论

军鼓是一个 14 号装备位驱动的持续流派 Buff 系统。它不是套装表效果，而是通过 `QFunction-0.txt` 的穿戴、卸下、掉落、攻击掉血前、受击掉血前、宝宝攻击掉血前、死亡触发，以及 `QManage.txt` 的登录和定时器刷新共同维持。

当前配置是 54 件军鼓：3 个职业 * 3 个方向 * 6 个品质。配置表用精确名称匹配，不做模糊匹配。

军鼓效果分为三层：

- 常驻短时属性层：佩戴后每 2 秒刷新一次，模块内用 `ChangeHumAbility ... 3` 和 `AddHumNewValue ... 3` 给 3 秒属性窗口。
- 战斗触发层：在 `@AttackDamage`、`@StruckDamage`、`@SlaveAttackDamage` 中用 `ChangeDamageValue` 调整本次伤害百分比，或用 `HumanHP` 回血。
- 图标和目标标记层：自身用 `SetArrBuff 1 87 ... -1 ...` 做常驻 Buff 图标，部分方向给目标写 `S$军鼓雷痕/火种/毒印` 并显示目标 Buff 或头戴图标。

需要特别注意：当前只有战士三方向的战斗触发使用了 `RANDOMEX <$STR(N$军鼓触发几率)> 100`。法师和道士方向的攻击、受击、宝宝触发没有概率门，条件满足即结算。`ItemDescList.txt` 多处写了“几率结算”，这与当前法师/道士实现不完全一致。

## 配置映射

配置入口是 `军鼓流派配置.txt` 的 `[@军鼓配置_读取]`。流程是：

1. `GetStringPosEX ..\QuestDiary\系统功能\军鼓流派配置.txt <$STR(S$军鼓名称)> N$军鼓配置行 S$军鼓配置文本 0` 查找当前 14 号位装备名。
2. 未找到时 `N$军鼓有效` 保持 0，刷新逻辑会清理军鼓状态。

### 刷新逻辑

`军鼓BUFF.txt:4` `[@军鼓BUFF_刷新]` 是主入口：

- 先用 `CHECKUSEITEM 14` 判断 14 号位是否有装备，没有就清理。
- 用 `GetItemFieldValue 14 name S$军鼓名称` 读取当前装备名。
- 调用配置读取，确认是否是 54 件军鼓之一。
- 用 `CHECKJOB warrior/wizard/taoist` 确认职业匹配。
- 若当前名称、方向、职业、品质没有变化，则调用当前模块刷新并刷新图标。
- 若发生切换，则先关闭旧模块，再写入 `S$军鼓当前名称/方向/职业` 和 `N$军鼓当前品质`，开启新模块并刷新图标。

`军鼓BUFF.txt:661` `[@军鼓BUFF_战斗确认]` 是战斗前确认：

- 再次确认 14 号位存在。
- 再次读取 14 号位名称，与缓存的 `S$军鼓当前名称` 精确比较。
- 再次检查职业匹配。
- 失败时清理或刷新，成功才把 `N$军鼓战斗确认` 置 1。

### 清理逻辑

`军鼓BUFF.txt:712` `[@军鼓BUFF_清理]`：

- `CloseArrBuff 87` 关闭自身自动排列 Buff。
- `SETICON 1 -1` 清自身头戴位 1。
- `SETOFFTIMER 87` 停掉军鼓定时刷新。
- 调用 `@军鼓BUFF_关闭当前模块` 清方向标记。
- 清空当前名称、方向、职业、品质、图标说明、触发说明等变量。

注意：各方向的常驻属性是 `ChangeHumAbility ... 3` / `AddHumNewValue ... 3` 的 3 秒窗口。清理时没有逐项 `= 0`，而是停刷新后等待短时属性自然到期。

核心代码：

```txt
CloseArrBuff 87
```

## 属性编号说明

`ChangeHumAbility` 的编号来自手册 `340-调整人物属性.md`。军鼓脚本用到：

| 编号 | 含义 |
| ---: | --- |
| 1 / 2 | 防御下限 / 防御上限 |
| 3 / 4 | 魔御下限 / 魔御上限 |
| 5 / 6 | 攻击下限 / 攻击上限 |
| 7 / 8 | 魔法下限 / 魔法上限 |
| 9 / 10 | 道术下限 / 道术上限 |
| 11 / 12 | MaxHP / MaxMP |
| 14 / 15 | HP 恢复 / MP 恢复 |
| 16 / 17 | 毒恢复 / 毒躲避 |
| 18 | 魔法躲避 |
| 19 | 准确 |

`AddHumNewValue` 的编号来自手册 `387-增加隐藏元素属性.md`。军鼓脚本用到：

| 编号 | 手册含义 |
| ---: | --- |
| 0 | 暴击几率增加 |
| 1 | 增加攻击伤害 |
| 2 | 物理伤害减少 |
| 3 | 魔法伤害减少 |
| 4 | 忽视目标防御 |
| 5 | 所有伤害反弹 |
| 11 | 增加杀怪暴率 |
| 19 | 增加防止冰冻 |
| 24 | 暴击抗性 |

脚本变量名 `N$军鼓元素` 只是本模块的数值桶，不代表每一处都是传统意义的火、冰、雷元素；实际效果要看 `AddHumNewValue` 的属性编号。
