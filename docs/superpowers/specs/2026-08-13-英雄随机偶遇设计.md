# 英雄随机偶遇设计

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标:** 将英雄开放由手动设置全局变量 G3 改为在全局进程到达赤月阶段 (G0≥4) 后，每小时 2% 概率在盟重安全区生成临时 NPC“英雄引路人”。任意玩家与之对话后，将 G3 设为 1、全服公告、NPC 立即消失，全服英雄功能永久开放。

**设计原则:** 只做静态文本编辑，不编译、不启动服务端；保留原始编码与缩进习惯；沿用现有 G3 全局变量和酒馆入口检查；基于已验证的机器人定时与动态 NPC 命令。

**设计批准:** ✅ (用户同意方案 A)

## 触发条件与流程

1. **阶段条件**：`G0>=4`（赤月阶段已开放）且 `G3=0`（英雄未开放）
2. **概率判定**：每小时整点执行一次判定，2% 概率触发（即 100 次中平均出现 2 次）
3. **NPC 生成**：触发后在盟重安全区（地图编号 `3`）随机坐标生成 NPC“英雄引路人”
4. **玩家交互**：任意玩家可以与 NPC 对话，选择“确认开启英雄”后：
   - `MOV G3 1`
   - 全服公告：“英雄引路人已现身，<$USERNAME> 获得英雄传承，全服英雄功能正式开放！”
   - 立即删除本 NPC
5. **状态持久**：`G3` 为全局变量，服务器重启后仍然保持；NPC 消失后不再重复生成（因 `G3=1` 后满足条件 `G3=0` 不再成立）

## 详细脚本设计

### 1. 机器人定时入口 (`AutoRunRobot.txt`)

在文件末尾追加一行（保持原有编码与换行风格）：

```
#AutoRun NPC HOUR 1 @英雄偶遇
```

**解释**：
- `#AutoRun NPC HOUR 1`：每小时整点执行一次
- `@英雄偶遇`：跳转到 `QuestDiary\系统功能\随机英雄NPC.txt` 的对应标签

### 2. 核心调度脚本 (`QuestDiary\系统功能\随机英雄NPC.txt`)

```text
[@英雄偶遇]
{
#IF
LARGE G0 3
EQUAL G3 0
RANDOM 50
#ACT
#CALL [系统功能\随机英雄NPC.txt] @生成英雄引路人
}
```

```text
[@生成英雄引路人]
{
#IF
#ACT
DelNpc 英雄引路人 3
CreateNPC 英雄引路人 3 -1 -1 8 英雄引路人-3 1
SENDMSG 1 【英雄引路人】传说中的英雄引路人出现在盟重安全区，等待有缘人的到来。
}
```

**关键点**：
- `LARGE G0 3` 对应 `G0>=4`（赤月阶段）
- `EQUAL G3 0` 确保英雄尚未开放
- `RANDOM 50` 即 1/50 = 2% 概率
- `DelNpc` 先清理可能的残留 NPC（避免重复）
- `CreateNPC` 参数说明：
  - `英雄引路人` – NPC 显示名称
  - `3` – 地图编号（盟重安全区）
  - `-1 -1` – 随机坐标（引擎自动选择可达位置）
  - `8` – 外观编号（默认普通 NPC 外观）
  - `英雄引路人-3` – 脚本文件名（不带地图后缀，因第7参数为1）
  - `1` – 脚本文件不附带地图编号后缀
- `SENDMSG 1` 为全服公告，提示 NPC 出现

### 3. NPC 交互脚本 (`Market_def\英雄引路人-3.txt`)

```text
[@main]
#IF
#SAY
<Img:****:0:200:50>
英雄引路人：传说中，只有真正的勇者才能获得英雄的传承。\\\
你已经准备好迎接英雄的陪伴了吗？\\\
<确认开启英雄/@确认开启>   <再考虑一下/@exit>\\\
<离开/@exit>
```

```text
[@确认开启]
#IF
#ACT
MOV G3 1
DelNpc 英雄引路人 3
SENDMSG 1 【英雄引路人】英雄引路人已现身，<$USERNAME> 获得英雄传承，全服英雄功能正式开放！
#SAY
英雄引路人：愿你与英雄携手，共创传奇！\\\
<离开/@exit>
```

**关键点**：
- `@main` 为默认入口
- 使用 `<Img>` 可添加背景图片（图片ID需根据实际资源调整，若不需图片可省略）
- `@确认开启` 标签执行核心操作：设置 `G3=1`、删除 NPC、全服公告
- 删除 NPC 后，该地图不再有此 NPC，避免重复对话

## 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| NPC 生成位置不可达 | 使用 `-1 -1` 随机坐标，引擎自动选择可达点；已有 `杀怪触发.txt` 中类似用法已验证 |
| 概率判定与服务器时间不同步 | `#AutoRun NPC HOUR 1` 依赖引擎内置计时，与服务器时间一致；已有其他 `RUNONDAY` 调度正常工作 |
| 多玩家同时点击 NPC | 首个玩家点击后 `G3` 立即设为 1，NPC 删除；后续玩家即使同时点击，也会因 NPC 已删除而无法触发 |
| 服务器重启后 NPC 消失 | 设计预期：NPC 为临时生成，重启后消失；下次满足条件时会再次概率生成，不影响功能 |
| 公告刷屏 | 仅 NPC 出现公告一次 + 英雄开启公告一次，频率极低（平均每 50 小时一次） |
| 编码错误导致脚本失效 | 写入时严格遵守 GBK 编码，并参照同目录下的其他脚本格式 |

## 根据用户反馈调整

**调整一：NPC 生成地点从“盟重安全区”改为“野外随机地图”**

**“野外”定义**：已开放且非安全区、非建筑内部的开放地图。基于当前 G0≥4（赤月阶段已开放），以下地图视为可选的野外地图：

| 地图编号 | 地图名称 | 备注 |
|----------|----------|------|
| `0` | 比奇省 | 初始地图，非安全区 |
| `1` | 沃玛森林 | 阶段1已开放 |
| `2` | 毒蛇山谷 | 阶段2已开放 |
| `11` | 白日门 | 阶段4已开放 |
| `12` | 丛林迷宫 | 阶段4已开放 |
| `D1002` | 赤月峡谷广场 | 赤月地图，非安全 |
| `D1004` | 抉择之地 | 赤月地图，非安全 |
| `4` | 封魔谷 | 阶段5已开放 |

**选择逻辑**：当触发生成时，从上述列表中随机选取一个地图编号，作为 NPC 生成目标地图。

**调整二：NPC 对话不一定能成功开启英雄**

**成功概率**：对话后增加一次随机判定，`RANDOM 3` 表示 33% 概率成功（即 1/3 几率）。若失败，NPC 消失并提示“英雄传承的时机尚未到来”。

**失败处理**：
- NPC 立即删除，避免重复尝试
- 发送个人提示信息（`SENDMSG 5`）告知玩家
- 不影响后续再次生成（下一次概率触发仍可生成）

## 更新后的详细脚本设计

### 1. 核心调度脚本 (`QuestDiary\系统功能\随机英雄NPC.txt`)

```text
[@英雄偶遇]
{
#IF
LARGE G0 3
EQUAL G3 0
RANDOM 50
#ACT
#CALL [系统功能\随机英雄NPC.txt] @生成英雄引路人
}
```

```text
[@生成英雄引路人]
{
#IF
#ACT
DelNpc 英雄引路人 0
DelNpc 英雄引路人 1
DelNpc 英雄引路人 2
DelNpc 英雄引路人 11
DelNpc 英雄引路人 12
DelNpc 英雄引路人 D1002
DelNpc 英雄引路人 D1004
DelNpc 英雄引路人 4
MOV R$野外地图列表 0,1,2,11,12,D1002,D1004,4
GetRandomText <$STR(R$野外地图列表)> , A91
CreateNPC 英雄引路人 <$STR(A91)> -1 -1 8 英雄引路人-3 1
SENDMSG 1 【英雄引路人】传说中的英雄引路人出现在<$MAPTITLE(<$STR(A91)>)>，等待有缘人的到来。
}
```

**解释**：
- 使用 `GetRandomText` 从逗号分隔的列表中随机选取一个地图编号存入 `A91`
- 生成前先批量清除可能残留的 NPC（避免重复）
- 公告中使用 `<$MAPTITLE(...)>` 显示地图名称

### 2. NPC 交互脚本 (`Market_def\英雄引路人-3.txt`)

```text
[@main]
#IF
#SAY
<Img:****:0:200:50>
英雄引路人：传说中，只有真正的勇者才能获得英雄的传承。\\\
你已经准备好迎接英雄的陪伴了吗？\\\
<尝试接受传承/@尝试接受>   <离开/@exit>
```

```text
[@尝试接受]
#IF
RANDOM 3
#ACT
MOV G3 1
DelNpc 英雄引路人 <$MAP>
SENDMSG 1 【英雄引路人】英雄引路人已现身，<$USERNAME> 获得英雄传承，全服英雄功能正式开放！
#SAY
英雄引路人：愿你与英雄携手，共创传奇！\\\
<离开/@exit>
#ELSEACT
DelNpc 英雄引路人 <$MAP>
SENDMSG 5 英雄引路人：传承的时机尚未到来，下次再来试试吧。
#SAY
英雄引路人：传承的时机尚未到来，下次再来试试吧。\\\
<离开/@exit>
```

**关键点**：
- `RANDOM 3` 表示 1/3 概率成功
- 失败分支同样删除 NPC，避免重复尝试
- `<$MAP>` 获取当前地图编号，用于 `DelNpc` 命令

## 调整后的风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 随机选取的地图玩家无法到达 | 所选地图均在 G0≥4 时已开放（根据`地图开放.txt`），且均为野外非安全区 |
| 同一地图上已存在同名 NPC | 生成前批量 `DelNpc` 清理 |
| 成功概率过低导致玩家抱怨 | 33% 是较高概率，且 NPC 出现本身已是稀有事件；若需调整，后续可修改 `RANDOM` 参数 |
| 失败后 NPC 消失，玩家需等待下一次生成 | 符合“机遇”设计：不是每次遇到都能成功 |
