# 英雄随机偶遇实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按设计文档《英雄随机偶遇设计.md》实现功能：当G0≥4且G3=0时，每小时2%概率在随机野外地图生成NPC"英雄引路人"；对话有33%概率成功开启G3=1并全服公告，NPC立即消失。

**Architecture:** 新增两个脚本文件（Market_def、QuestDiary各一），修改一个机器人调度文件（AutoRunRobot.txt），保持GBK编码，沿用现有G3检查逻辑。

**Tech Stack:** 翎风脚本（Mir200）、PowerShell静态验证、Git。

### Task 2: 创建调度逻辑脚本

**Files:**

2. **写入调度逻辑内容（GBK编码）**
   ```powershell

   {
   #IF
   LARGE G0 3
   EQUAL G3 0
   RANDOM 50
   #ACT
   #CALL [系统功能\随机英雄NPC.txt] @生成英雄引路人
   }

   [@生成英雄引路人]
   {
   #IF
   #ACT
   DelNpc 英雄引路人 0
   DelNpc 英雄引路人 1
   DelNpc 英雄引路人 2
   DelNpc 英雄引路人 11
   DelNpc 英雄引路人 12
   DelNpc 英雄引路人 D1002
   DelNpc 英雄引路人 D1004
   DelNpc 英雄引路人 4
   MOV R$野外地图列表 0,1,2,11,12,D1002,D1004,4
   GetRandomText <$STR(R$野外地图列表)> , A91
   CreateNPC 英雄引路人 <$STR(A91)> -1 -1 8 英雄引路人-3 1
   SENDMSG 1 【英雄引路人】传说中的英雄引路人出现在<$MAPTITLE(<$STR(A91)>)>，等待有缘人的到来。
   }
   '@
   $bytes = [System.Text.Encoding]::GetEncoding("GBK").GetBytes($content)
   [System.IO.File]::WriteAllBytes("Mir200\Envir\QuestDiary\系统功能\随机英雄NPC.txt", $bytes)
   ```

### Task 3: 修改机器人定时器

**Files:**
- Modify: `Mir200\Envir\Robot_def\AutoRunRobot.txt`

1. **读取原文件内容（保留编码）**
   ```powershell
   $path = "Mir200\Envir\Robot_def\AutoRunRobot.txt"
   $content = Get-Content $path -Encoding Default -Raw
   if ($null -eq $content) { throw "文件读取失败或为空" }
   ```

2. **在文件末尾添加调度指令**
   ```powershell
   # 检查是否已存在相同调度
   if ($content -match '#AutoRun NPC HOUR 1 @英雄偶遇') {
       Write-Host "调度指令已存在，跳过" -ForegroundColor Yellow
   } else {
       # 去除末尾多余空行，保证新行从新行开始
       $content = $content.TrimEnd() + "`r`n`r`n#AutoRun NPC HOUR 1 @英雄偶遇`r`n"
       $bytes = [System.Text.Encoding]::GetEncoding("GBK").GetBytes($content)
       [System.IO.File]::WriteAllBytes($path, $bytes)
   }
   ```

3. **验证修改后的文件**
   ```powershell
   Get-Content $path -Encoding Default | Select-Object -Last 10
   ```
   Expected: 最后10行中包含 `#AutoRun NPC HOUR 1 @英雄偶遇`。

4. **检查机器人调度与标签映射**
