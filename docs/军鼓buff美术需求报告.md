## 引擎参数说明

### SetArrBuff

手册格式核心参数：

```txt
SetArrBuff 分组编号 按钮序号 WIL文件序号 图片序号 倒计时间 闪烁开始时间 闪烁图片开始序号 闪烁图片数量 文字备注
```

军鼓当前用法：

- 玩家自身常驻军鼓图标：`SetArrBuff 1 87 1 1681 -1 0 0 0 ...`
- 目标玩家临时减益图标：`M.SetArrBuff 3 X 20 图片号 持续秒数 0 0 0 ...`

### SETICON

手册格式核心参数：

```txt
SETICON 位置 WIL文件序号 图片序号 X Y 播放张数 播放效果 播放顺序 播放速度 是否仅自己可见
```

军鼓当前怪物目标占位：

```txt
M.SETICON 0 0 200 44 -30 10 0 0 150 0
```

含义：目标对象头戴位置 0，WIL 0，图片 200，坐标偏移 X=44/Y=-30，10 帧，普通播放，在角色前面，速度 150，所有人可见。

## 军鼓道具本体图标需求

当前 `docs/军鼓位玩法StdItems.csv` 中 54 件军鼓均为：

- `StdMode=65`
- `Shape=0`
- `Looks=0`
- `Anicount=0`
- `Weight=1`
- `DuraMax=8000`

这表示当前没有给军鼓分配独立道具外观。后期制作可以有两种路线：

| 方案 | 数量 | 优点 | 缺点 |
| --- | ---: | --- | --- |
| 9 个方向图标 + 6 套品质边框/底色 | 15 个基础资源左右 | 制作量低，方向辨识清楚 | 品质差异依赖边框规则 |
| 54 个独立道具图标 | 54 个 | 每件装备辨识度最高 | 制作量最大，后期维护成本高 |

建议采用第一种：每个方向一枚主图标，再用品质边框、底色或角标区分 6 档品质。

## 目标怪物头戴花翎特效

因为怪物没有玩家 BUFF 栏，目前三个目标状态都补了怪物头戴花翎占位：

```txt
M.SETICON 0 0 200 44 -30 10 0 0 150 0
```

当前这组参数来自挂机头戴特效的复用，占位可用，但不适合作为最终美术。

后期建议拆成三套：

| 方向 | 怪物头戴状态 | 建议资源 | 建议表现 |
| --- | --- | --- | --- |
| 电耗子 | 雷痕 | 新 WIL/图片号待分配 | 头顶闪电裂纹，蓝白电弧，10 秒 |
| 火葫芦 | 火种 | 新 WIL/图片号待分配 | 头顶小火苗/火葫芦印，5 秒 |
| 毒嘴子 | 毒印 | 新 WIL/图片号待分配 | 头顶毒雾/毒牙/咒印，10 秒 |

推荐参数保留当前显示位：

```txt
M.SETICON 0 <WIL> <图片起始号> 44 -30 10 0 0 150 0
```

如果后期美术帧数不是 10，需要同步调整第 6 参数。

## 后续落地提醒

1. 如果只替换 `SetArrBuff` / `SETICON` 编号，不需要改 54 件道具数据。
2. 如果要给军鼓道具分配背包图标，需要同步维护 `StdItems` 的外观字段，并保留 `docs/军鼓位玩法StdItems.csv` 作为规格源。
3. 如果 9 个方向要使用不同自身 BUFF 图标，需要修改 `军鼓BUFF_刷新图标`，按 `S$军鼓当前方向` 选择图片号。
4. 如果怪物头戴花翎从统一占位改成三套资源，需要修改法师/道士军鼓流派脚本中的 5 处 `M.SETICON`。
5. 修改脚本时继续按本项目规则保留 GBK/ANSI 编码；本文档位于 `docs/`，按 UTF-8 维护。
