## 二、生效链路（阶段1覆盖）

英雄穿军鼓 / 英雄登录 → `@英雄军鼓_刷新`
1. `CheckHeroOnline` 在场守卫；
2. `H.CHECKUSEITEM 14` 确认英雄 14 号位佩戴；
3. `H.GetItemFieldValue 14 name` 读英雄军鼓名；
4. 用 `GetStringPosEX + ExtractStringEx` **独立**解析 `军鼓流派配置.txt`（**不复用玩家 `@军鼓配置_读取`**，避免污染玩家 `S$军鼓*/N$军鼓*` 变量），落到"英雄军鼓"独立变量域；
5. `@英雄军鼓_职业确认`：`CheckHeroJob` 与军鼓职业一致；
6. `@英雄军鼓_读取品质数值` 按品质写入与玩家同值的数值桶；
7. `@英雄军鼓_应用常驻`：按职业用 `H.ChangeHumAbility` 直发 3 秒短窗口核心属性：
   - 战士：防御下限/上限(1/2) + MaxHP(11)
   - 法师：魔法下限/上限(7/8) + MaxMP(12)
   - 道士：道术下限/上限(9/10) + MaxHP/MaxMP(11/12)
8. `@英雄军鼓_刷新战士攻速` / `_刷新法师施法速度` 统一汇总。

定时续期：玩家 87 定时器每 2 秒调 `@英雄军鼓_定时检查`，英雄在线且 14 号位仍在、名称未变 → 重发 3 秒窗口与攻速/施法速度。

清理：英雄卸下(14号位)/死亡/配置失效 → 停状态、清零属性、攻速施法速度经统一入口归零（未穿追风流/法师军鼓时为 0）。

## 三、英雄侧命令实机验证点（本阶段已使用，但引擎前缀可用性请实测）

- `H.CHECKUSEITEM 14`（英雄 14 号位在位检测）
- `H.GetItemFieldValue 14 name`（读英雄装备名）
- `H.ChangeHumAbility` / `H.LockUpdateAbil` / `H.UpdateAbil`（英雄属性直发）
- `H.CHANGESPEED 2/3`（英雄攻速/施法速度）
- `CheckHeroOnline` / `CheckHeroJob WARRIOR|WIZARD|TAOIST`

> 若实测发现 `H.CHECKUSEITEM` / `H.GetItemFieldValue` 不可用，`@英雄军鼓_刷新` 会落 `#ELSEACT` 走清理（安全降级：英雄军鼓不生效但不报错）。请将实测结果反馈，再据实补阶段 2。

## 四、测试建议（实机）

1. 玩家召唤英雄 → 给英雄 14 号位穿一件军鼓（如 `粗坯·剁馅机`，战士英雄）→ 观察英雄是否获得对应属性（战士：防御下限/上限、MaxHP；剁馅机方向攻速随品质提升）。
2. 卸下军鼓 → 英雄属性应回落。
3. 英雄上线（身上已穿军鼓）→ 应自动结算，无需重穿。
4. 换穿不同职业/方向军鼓 → 职业不匹配时应不生效并清理。
