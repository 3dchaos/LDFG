## 二、攻击向规则（与玩家方向数值一致，命令换 H./H.M. 前缀）

| 英雄军鼓职业/方向 | 效果（@HeroAttackDamage 内按触发几率） |
| --- | --- |
| warrior·拆门板 | 目标非玩家(`NOT H.CHECKCURRTARGETRACE = 0`) + 几率：`H.M.HumanHP - 切割`（对当前攻击目标怪物直扣最大生命比例） |
| warrior·剁馅机 | 同上，`H.M.HumanHP - 追风切割` |
| wizard·小冰箱/电耗子/火葫芦 | 几率：`H.ChangeDamageValue 1 + 百分`（给英雄本次攻击伤害加百分比） |
| taoist·毒嘴子/养娃人 | 几率：`H.ChangeDamageValue 1 + 百分` |

> 触发均在 `@HeroAttackDamage`（英雄攻击目标掉血前）内执行。命令依据：
> - `@HeroAttackDamage` + `H.ChangeDamageValue` → 手册 796
> - `H.CHECKCURRTARGETRACE` → 手册 103
> - `H.M.HumanHP`（英雄操作当前攻击目标）→ 手册 164 多级运用

## 三、设计取舍与范围界定

- **法师/道士攻击向采用"技能名无关的通用触发"**：玩家侧是按 `CHECKMAGICNAME`(当前技能) 细分（电耗子雷电/疾光/雷光、火葫芦火球/大火球/地狱火、小冰箱冰咆哮/寒冰掌/冰霜群雨、毒嘴子施毒/火符/诅咒）。英雄侧未用英雄技能判断命令细分（手册无 `H.CHECKMAGICNAME` 实锤），改为"英雄任意攻击按几率加百分比"，数值完全复用玩家同品质 `百分`。若实机需限定技能，可在英雄攻击技能判断命令验证后再细分。
- **暂缓（命令缺英雄版依据 / 属第二层表现）**：法师满层 `RangeHarm` 范围冰冻/火种层数、道士毒印状态(`M.SetArrBuff`/`M.SETICON`/`M.ChangeState` 给目标挂状态)、养娃人宝宝联动(`@HeroSlaveAttack`)——这些在玩家侧依赖 `CHECKMAGICNAME` 与对目标挂状态，英雄版命令未逐条实锤，等阶段 1+2 攻击向实机通过后按需补。
- **切割/加伤主体命令用 `H.`（作用于英雄自身/英雄本次伤害），作用于当前攻击目标用 `H.M.`**，遵循"作用于当前主体加 H.、作用于当前目标加 H.M."原则。
